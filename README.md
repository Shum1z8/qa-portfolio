### 4. Chrome DevTools

Проверял сайт через DevTools:
- Смотрел Network: какие запросы уходят, какие статусы приходят.
- Смотрел Console: есть ли ошибки JS.

Примеры:
- В Network видел запросы со статусом 200 (успех) и 204 (успех без тела ответа).
- Пример: запрос к главной странице сайта вернул статус 200, значит страница загрузилась успешно.
- В Console находил ошибку "Extension context invalidated". Это ошибка расширения Chrome, а не сайта.
- Видел запросы со статусом Blocked из-за CORS или расширений браузера. Это не ошибка сайта, а особенность настройки браузера.
- Вывод: в проверенных сценариях не обнаружил ошибок JS, связанных с сайтом.
- Что бы залогировал как баг: если бы увидел ошибку JS, которая ломает функциональность, например кнопка не работает, оформил бы баг-репорт с шагами, ожидаемым и фактическим результатом, скриншотом.
