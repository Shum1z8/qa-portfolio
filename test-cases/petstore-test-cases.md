# Тест-кейсы — Swagger Petstore API

## TC-001: Создание питомца
- Предусловия: API доступен.
- Шаги:
  1. Отправить POST /pet с валидным JSON.
  2. Проверить ответ.
- Ожидаемый результат: 200 OK, питомец создан.

## TC-002: Получение питомца по ID
- Предусловия: Питомец с ID 676767 существует.
- Шаги:
  1. Отправить GET /pet/676767.
  2. Проверить ответ.
- Ожидаемый результат: 200 OK, данные питомца совпадают с созданными.

## TC-003: Обновление питомца
- Предусловия: Питомец с ID 676767 существует.
- Шаги:
  1. Отправить PUT /pet с новыми данными.
  2. Проверить ответ.
- Ожидаемый результат: 200 OK, данные обновлены.

## TC-004: Удаление питомца
- Предусловия: Питомец с ID 676767 существует.
- Шаги:
  1. Отправить DELETE /pet/676767.
  2. Проверить ответ.
- Ожидаемый результат: 200 OK, питомец удалён.

## TC-005: Получение несуществующего питомца
- Предусловия: Питомца с ID 999999 не существует.
- Шаги:
  1. Отправить GET /pet/999999.
  2. Проверить ответ.
- Ожидаемый результат: 404 Not Found.
