# Баг-репорты — Swagger Petstore API

## BUG-001: Некорректный статус при получении несуществующего питомца
- Приоритет: Medium
- Серьёзность: Minor
- Окружение: Chrome, Postman
- Шаги:
  1. Отправить GET /pet/999999.
- Фактический результат: сервер возвращает 404 Not Found.
- Ожидаемый результат: 404 Not Found.
- Статус: Не баг (проверка негативного сценария).

## BUG-002: Создание питомца с пустым именем
- Приоритет: High
- Серьёзность: Major
- Окружение: Chrome, Postman
- Шаги:
  1. Отправить POST /pet с JSON, где "name" пустая строка.
- Фактический результат: сервер может принять запрос.
- Ожидаемый результат: 400 Bad Request, ошибка валидации.
- Статус: Потенциальный баг (проверить валидацию).

## BUG-004: Обновление несуществующего питомца
- Приоритет: Medium
- Серьёзность: Minor
- Окружение: Chrome, Postman
- Шаги:
  1. Отправить PUT /pet с ID 999999.
- Фактический результат: сервер может вернуть 200 OK или 404.
- Ожидаемый результат: 404 Not Found, если питомца нет.
- Статус: Потенциальный баг (проверить логику).
