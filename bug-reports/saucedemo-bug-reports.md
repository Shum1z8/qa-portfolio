# Баг-репорты — SauceDemo

Тестировал учебного пользователя problem_user с преднамеренными дефектами, чтобы отработать оформление баг-репортов.

## BUG-01: Кнопка Add to cart не работает

Шаги:
1. Войти под problem_user.
2. Открыть каталог.
3. Нажать Add to cart у товара.

Ожидаемый результат: товар добавляется в корзину.

Фактический результат: кнопка не активна, товар не добавляется.

Серьёзность: High.
Приоритет: High.
Окружение: Google Chrome, Windows 11.
